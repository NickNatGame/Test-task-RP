# IterGen на SQL

Тестовое задание: сравнение обычной генерации, SynCode и собственного цикла IterGen на `Qwen/Qwen3.5-0.8B`. Основная выборка — 50 задач Spider из пяти баз, ещё 5 задач используются для отладки. Seed — 228.

## Что лежит в репозитории

- [Test_task_RP.ipynb](Test_task_RP.ipynb) — код экспериментов и пояснения.
- [REPORT.pdf](REPORT.pdf) — краткий отчёт с результатами.
- [TRACE_EXAMPLES.md](TRACE_EXAMPLES.md) — разбор конкретных запросов и откатов.
- [results/seed_228/](results/seed_228/) — выборка, предсказания, метрики, настройки и трассы.

## Как запустить

Нужен Python 3.10 и локальная библиотека `itergen/` с патчами для Qwen3.5 и SynCode.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install ipykernel
```

Открой ноутбук с ядром `.venv/bin/python` и выполняй ячейки по порядку. Установка зависимостей находится в начале ноутбука. Перед запуском проверь `cache_dir` и наличие SQLite-баз; если их нужно скачать, заполни `SPIDER_URL` — сейчас там пробел.

Готовые ответы подхватываются из папки результатов. После изменения кода библиотеки перезапусти ядро; для нового эксперимента с изменёнными настройками используй отдельную папку. Версии окружения записаны в [run_config.json](results/seed_228/run_config.json).

Грамматика, загрузчик данных и методы IterGen взяты у авторов. Контроллер проверок и откатов, оценка SQL и сохранение результатов реализованы для задания; происхождение кода отмечено в комментариях ноутбука.
